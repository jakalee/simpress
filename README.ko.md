# Simple Impress Editor

[English](README.md) · [편집기 바로 열기](https://jakalee.github.io/simpress/) · [인터랙티브 기능 데모](https://jakalee.github.io/simpress/example/feature-showcase.html) · [최신 버전 다운로드](https://github.com/jakalee/simpress/releases/latest)

> 비공개·오프라인 우선·단일 파일 방식의 impress.js 비주얼 프레젠테이션 편집기입니다.

**설치도, 계정도, 서버도 필요 없습니다.** 무한 캔버스에 콘텐츠를 배치하고 프레임을 발표 경로로 연결한 다음, 독립 실행형 HTML 파일 하나로 내보낼 수 있습니다.

## 인터랙티브 기능 쇼케이스

[![SIMPress 인터랙티브 기능 쇼케이스](example/preview.png)](https://jakalee.github.io/simpress/example/feature-showcase.html)

**[인터랙티브 기능 데모 실행하기 →](https://jakalee.github.io/simpress/example/feature-showcase.html)**

이 소개자료도 SIMPress로 직접 만들고 HTML 하나로 내보낸 결과물입니다. 3D 제품을 직접 돌리고, 대시보드의 제품군과 부하 슬라이더를 바꾸고, p5.js 필드 시뮬레이션과 화이트보드를 실행해 보세요. `O` 키를 누르면 전체 공간 구성을 볼 수 있습니다. 조작법과 샘플 자료 출처는 [데모 설명서](example/README.md)에 정리했습니다.

## 이런 걸 할 수 있습니다

- **확대·회전하며 날아다니는 발표를 HTML 파일 하나로** — 줌·회전·3D 깊이 이동. 받는 사람은 프로그램 없이 브라우저로 열기만 하면 됩니다.
- **AI가 덱을 통째로** — 주제만 적으면 ChatGPT·Claude·Gemini 등 아무 AI 채팅으로 개요를 받아 템플릿 슬라이드와 발표자 노트까지 자동 생성. API 키도 서버도 필요 없습니다.
- **발표 화면 안에서 진짜로 움직이는 웹페이지** — p5.js 시뮬레이션, 지도, 3D 그래프, 직접 만든 HTML 앱을 슬라이드에 넣고 발표 중에 바로 클릭·드래그로 조작. 편집 화면에서도 실제 실행된 모습이 보입니다.
- **CAD 모델을 발표 중에 돌려 보기** — STEP·IGES·STL·GLB를 넣으면 청중 앞에서 마우스로 회전, 부품별 숨기기·색 바꾸기.
- **엑셀에서 복사 → 붙여넣기 → 애니메이션 차트** — 범위를 그대로 붙이면 SVG 차트 8종으로.
- **어디서든 복사해 붙여넣기** — 스크린샷, 웹 이미지, Apple 프리폼(Freeform)·키노트에서 복사한 도형과 그림도 ⌘V로 바로 들어옵니다 (이미지로 붙여넣어짐).
- **번역 버튼 하나로 다국어 발표** — 내보낸 HTML의 글자는 모두 진짜 텍스트라서, Chrome의 페이지 번역으로 영어·일본어·중국어 등 원하는 언어로 바로 바뀝니다. 같은 파일을 해외 청중에게 그대로 보내도 됩니다.
- **발표자 콘솔** — 노트, 현재·다음 슬라이드, 타이머를 별도 창으로. 프레젠테이션 리모컨(PageUp/PageDown)도 됩니다.
- **PDF 배포본도 한 번에** — 슬라이드 한 장 = PDF 한 쪽, 글자는 벡터 그대로.
- **내 컴퓨터 밖으로 나가지 않음** — 계정·업로드 없이 브라우저 안에서만 저장됩니다.

## 왜 만들었나요?

- **기본적으로 비공개** — 작성한 프레젠테이션은 브라우저 안에 머뭅니다.
- **설정이 필요 없음** — `index.html`을 열면 바로 실행되며 패키지 설치나 빌드 과정이 없습니다.
- **시각적인 3D 편집** — 객체를 이동·확대·회전하고 깊이 방향으로 배치할 수 있습니다.
- **간편한 전달** — 완성한 발표를 독립 실행형 HTML 파일 하나로 내보냅니다.

## 시작하기

1. [라이브 데모](https://jakalee.github.io/simpress/)를 열거나 [`index.html`](index.html)을 내려받습니다.
2. 캔버스에 텍스트, 이미지, 도형, 프레임, 영상을 추가합니다.
3. 객체를 발표 경로로 연결하고 미리 본 뒤 **HTML 내보내기**를 선택합니다.

## 주요 기능

- 이동과 확대·축소가 가능한 무한 캔버스
- 프레임과 발표 경로 편집
- 이동, 크기, 회전, X/Y축 기울기, Z축 깊이 조절
- 텍스트, 이미지, 도형, 로컬 영상, YouTube 링크
- 발표자 노트, 슬라이드 탐색기, 진행 표시
- 자동 저장, 실행 취소·다시 실행, JSON 저장·불러오기
- 로컬 자산을 포함한 독립 실행형 HTML 내보내기
- 슬라이드별 PDF 내보내기 (한 슬라이드 = 한 페이지, 글자는 벡터, 3D 모델은 스냅샷)
- 메뉴 막대(파일·편집·삽입·슬라이드·레이어·보기·도움말)와 단축키 도움말(`?`)
- 16:9 슬라이드 추가·복제·삭제·순서 이동, 레이어 패널(겹침 순서·잠금·숨김)
- 슬라이드 레이아웃 7종(표지·섹션·글머리표·2단·이미지+글·마무리·빈 슬라이드)과 덱 템플릿 5종 — 테마·프레임·캔버스 배치(가로·격자·방사형 줌·3D 계단)를 묶어 한 번에 만들기
- AI로 덱 만들기 — 주제를 적고 프롬프트를 복사해 아무 AI 채팅에 붙여넣은 뒤, 돌아온 개요(JSON)를 붙여넣으면 템플릿으로 슬라이드와 발표자 노트를 만듭니다 (서버·API 키 불필요)
- 도형 24종(다각형·별·도넛·화살표·설명선·순서도 등)과 도형 안 글
- 표(칸 편집, Tab 이동, 행·열 추가)
- SVG 차트 8종 — 엑셀 범위 붙여넣기, 대용량 데이터 자동 축약, 발표 시 애니메이션
- 객체를 따라오는 연결선(직선·꺾은선·곡선)과 펜(자유 그리기)
- 인터랙션 — 마우스 올리기·누르기(슬라이드 이동, 링크, 보이기/숨기기, 자바스크립트 실행)·단계 진입 효과
- 3D 모델 — GLB·glTF·STL·OBJ와 CAD(STEP·IGES)를 불러와 발표 화면에서 실시간으로 돌리기(자동 회전·마우스 회전·애니메이션), 부품별 보이기·색 바꾸기. CAD 변환기와 three.js는 버전을 고정한 CDN에서 필요할 때만 불러오며, 인터넷이 없으면 스냅샷 이미지가 대신 보입니다
- 웹 임베드 — 한 파일로 된 HTML(문서 안에 포함)이나 웹 주소를 슬라이드 안에 띄우기. 격리(sandbox)되어 실행되고, 편집 화면·전체 보기에서도 실제로 실행된 모습이 보이며 발표 중 바로 클릭으로 조작됩니다. 무거운 페이지는 "보일 때만 실행"으로 해당 슬라이드에서만 돌릴 수 있고, 인터넷이 없어 라이브러리를 못 불러오면 자리표시로 돌아갑니다. p5.js 예제(단진자·파동·입자·3상 회전 자계) 포함
- PDF 불러오기 — PowerPoint·Keynote에서 PDF로 저장한 파일을 열면 페이지마다 슬라이드로 (레티나에서도 선명한 4K 해상도, 경로 자동 연결)
- 웹 임베드·영상·3D를 넣으면 지금 보는 슬라이드에 꽉 차게, "슬라이드에 꽉 채우기" 버튼, 영상 컨트롤바 숨기기
- 붙여넣기 — 클립보드의 이미지(스크린샷, Apple 프리폼·키노트에서 복사한 도형 등)를 ⌘V로 바로 삽입
- 다국어 — 내보낸 HTML은 모두 실제 텍스트라 Chrome 페이지 번역 등으로 원하는 언어로 바꿔 볼 수 있음

## AI로 발표자료 만들기 스킬

[`skill/simpress-deck`](skill/simpress-deck/)은 작업지시서와 자료(pptx·pdf·svg·영상)를 주면 AI 에이전트가 simpress 발표자료(HTML + 편집용 JSON)를 만들어 주는 스킬입니다. Claude·Claude Code·기타 에이전트에 설치하는 법과 요청 양식은 [지침서](skill/simpress-deck/README.md)를 보세요.

## 개인정보와 이식성

프레젠테이션 데이터는 브라우저에 저장되며 이 프로젝트가 서버로 업로드하지 않습니다. 다만 3D 모델(three.js·CAD 변환기)과 p5.js 예제를 쓰면 해당 라이브러리를 jsDelivr CDN에서 내려받습니다 (문서 내용은 보내지 않음). 브라우저 데이터를 지우면 자동 저장 문서도 사라지므로 중요한 작업은 JSON으로 저장해 두세요.

내보낸 발표에는 impress.js의 필수 MIT 고지가 포함됩니다. 로컬 자산은 내보낸 파일에 포함되지만 YouTube 재생과 썸네일에는 인터넷 연결이 필요합니다.

사용자가 추가하거나 재배포하는 이미지, 영상, 글꼴 및 기타 콘텐츠의 이용 권한은 해당 사용자에게 있습니다.

## 브라우저 지원

현대적인 데스크톱 브라우저를 대상으로 합니다. Chrome, Edge, Safari, Firefox 사용을 권장합니다. 모바일 편집은 아직 최적화되어 있지 않습니다.

## 프로젝트 구조

편집기와 impress.js 런타임이 [`index.html`](index.html) 하나에 포함되어 있어 서버나 빌드 도구 없이 실행할 수 있습니다.

`index.html`은 `src/`(편집기 코드)와 `vendor/impress.js`를 합쳐 만든 결과물입니다. 코드를 고칠 때는 `src/`를 수정한 뒤 `python3 build.py`로 다시 만드세요. `index.html`을 직접 고치면 다음 빌드에서 덮어써집니다.

누르면 실행되는 사용자 자바스크립트는 편집 화면에서는 실행되지 않으며, 다른 사람이 만든 파일을 열 때는 코드를 유지할지 묻습니다. 내보낸 HTML을 여는 브라우저에서는 그대로 실행되므로 출처를 모르는 발표 파일은 주의해서 여세요.

버그 제보와 기능 제안은 [Issues](https://github.com/jakalee/simpress/issues)에서, 코드 기여는 Pull Request로 환영합니다.
